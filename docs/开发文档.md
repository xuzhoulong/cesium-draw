# 绘制工具开发文档（DrawTool）

基于 Cesium 的图形绘制工具库，支持绘制**线、点、矩形、多边形、圆、椭圆**，并提供编辑（顶点拖拽 / 整体拖拽）、右键菜单、事件监听、停止/清除绘制等能力。

---

│       ├── drawLine.js        # 画线

## 二、架构分层

```
┌─────────────┐   type    ┌──────────────┐   调用    ┌──────────────────┐
│  gui.js     │ ────────▶ │ drawActions  │ ───────▶ │ drawTool.js (Draw)│
│ （按钮层）   │  "line"等  │ （动作层）    │ startDraw │ （核心类）         │
└─────────────┘           └──────────────┘           │   ├ 公共工具方法    │
                                                     │   ├ 事件系统        │
                                                     │   ├ 绘制分发 startDraw│
                                                     │   └ 编辑/菜单/清理   │
                                                     └────────┬─────────┘
                                                              │ drawLineModule(this, options)
                                                     ┌────────▼─────────┐
                                                     │ js/modules/*.js  │
                                                     │ （各类型绘制模块） │
                                                     └──────────────────┘
```

- **绘制模块模式**：每个模块默认导出一个 `(ctx, options)` 函数，`ctx` 为 Draw 实例（this），通过 `ctx` 调用公共方法，主类保持精简。
- **shape 数据模型**：每次绘制创建一个独立的 `shape` 对象，结构：
  ```js
  {
    type: "line" | "point" | "rect" | "polygon" | "circle" | "ellipse",
    id,               // 自定义实体 id（可选）
    points,           // 坐标数组（线/多边形=顶点；矩形=2对角点；圆=圆心+半径点；椭圆=圆心+长轴点+短轴点）
    mainEntity,       // 主实体（polyline / polygon / ellipse / point）
    tempEntity,       // 预览实体（虚线/预览面，部分模块有）
    tempDashEntity,   // 预览虚线（多边形专用）
    pointsEntity,     // 顶点实体数组（编辑拖拽用）
    success,          // 完成回调
    style,            // { lineWidth, color, pointSize, clampToGround }
    firstPointTime,   // 第一个点点击时间（线/多边形，识别"双击画第一个点"）
    updatePoint,      // 可选：矩形等特殊形状的顶点联动更新函数
    finish,           // 可选：完成函数（模块内部 finishDraw/finish）
  }
  ```

## 三、核心类 API（js/drawTool.js）

### 图层与实体所有权

`config.dataSource` 可传入已由业务侧挂载的 `Cesium.CustomDataSource`；省略时自动创建并挂载默认图层。公开属性 `dataSource` 提供图层管理，`ready` 为默认挂载的 Promise（外部图层直接返回已解决的 Promise，不代替业务挂载）。

全部实体创建、查询与删除通过内部 `_entities` 适配器处理；适配器以 Set 跟踪当前实例创建的实体，包括预览、标签及编辑辅助点。`clear()` 仅删除该集合，逐个发送已完成图形的 `removeGraphic`，不删除共享图层中的其他业务对象，也不移除图层。同 ID 的外部实体禁止覆盖。新增模块不得再直接操作 `viewer.entities`。

### 存储与静默加载管线

公开接口 `getGraphic(id)` / `getGraphics()` 导出 `{ id, type, positions, style }` 快照，`addGraphic(data)` / `loadGraphics(dataList)` 同步返回新增快照。坐标和样式复制，不更改原事件载荷；业务在 `drawEnd`、`editStop` 查询快照保存。详细输入格式见使用文档。回显省略 `id` 或传入 `undefined` 时由 `_normalizeGraphic` 调用 `Cesium.createGuid()` 生成，返回及导出保留生成值，不修改输入；显式非法 ID 与 ID 冲突仍拒绝。

加载流程：检查空闲状态 → `_normalizeGraphic` 全量校验并复制 → 检查已有及批内 ID → 各模块 `createXxxGeometry` 创建 → `_registerShape` 初始化隐藏辅助点并登记 → 启用空闲拾取。

- 六个模块的具名 geometry factory 同时用于交互与回显，不启动 handler，也不调用 `completeShape`。
- `rectCorners` 和 `updatePoint` 统一矩形四角与对角点模型；圆、椭圆共用控制点距离和 CallbackProperty 算法。
- `_registerShape` 仅负责辅助点和登记；`completeShape` 继续承担 `drawEnd` → `success` → 可选自动编辑。回显不经过此交互完成流程。
- 主实体、顶点和中心点全部经 `_entities` 跟踪。加载前记录所有权快照和 shapes 长度；创建异常时删除新增实体、撤销本批登记，并清理本批新建的空闲 handler。
- `_loadingGraphics` 阻止加载重入；绘制或编辑期间直接拒绝加载，不隐式停止操作。
- 加载不覆盖 ID、不自动清空、不发绘制或编辑开始事件；后续编辑、菜单和删除沿用原逻辑。`clear()` 的删除事件与图层所有权契约保持不变。

新增类型时，除交互分发外还须扩展加载校验、geometry factory 映射及往返测试。

验证命令：`node tests/graphics.test.mjs`。测试加载仓库真实 Cesium 数据模型，以最小鼠标 handler / DOM 桩验证六种图形往返、静默事件、坐标联动、编辑增删、校验、回滚和共享图层隔离；它不替代浏览器 WebGL 渲染验证。

### 3.1 构造函数

```js
new Draw(viewer, config);
```

| 参数                | 类型          | 说明                                                                                                                   |
| ------------------- | ------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `viewer`            | Cesium.Viewer | 必传                                                                                                                   |
| `config.style`      | object        | 默认样式 `{ lineWidth, color, pointSize, clampToGround }`（兼容旧写法直接传 `{ lineWidth, ... }`）                     |
| `config.enableEdit` | boolean       | 是否支持编辑，默认 `true`；为 `false` 时禁用所有编辑入口（点击实体 / 右键「开始编辑」/ 自动编辑），`autoEdit` 随之失效 |
| `config.autoEdit`   | boolean       | 绘制完成后是否自动进入编辑，默认 `true`（仅在 `enableEdit` 为 `true` 时生效）                                          |

### 3.2 绘制入口 `startDraw(options)`

支持**回调**与**异步（Promise）**两种调用方式：

```js
// 回调方式
draw.startDraw({
  id: "line1",            // 可选：自定义实体 id
  type: "line",           // 必传：line / point / rect / polygon / circle / ellipse
  style: { color: "#0092ff" },  // 可选：本次绘制样式，覆盖默认
  success: (result) => { ... }, // 可选：绘制完成回调
});

// 异步方式
const result = await draw.startDraw({ type: "rect" });
// result = { id, positions, type }
```

> 传了 `success` 走回调（返回 undefined）；不传返回 Promise，resolve 结果对象。

### 3.3 各类型绘制方法（内部由 startDraw 分发）

| 方法                   | type        | 交互                                               |
| ---------------------- | ----------- | -------------------------------------------------- |
| `drawLine(options)`    | `"line"`    | 单击加点、右键删点（虚线实时重绘）、双击结束       |
| `drawPoint(options)`   | `"point"`   | 单击放置点即完成（鼠标移动有预览点）               |
| `drawRect(options)`    | `"rect"`    | 两点对角：第一点起点、第二点对角，预览矩形实时跟随 |
| `drawPolygon(options)` | `"polygon"` | 单击加点、预览面实时闭合、右键删点、双击结束       |
| `drawCircle(options)`  | `"circle"`  | 第一点圆心、第二点半径点（预览圆实时跟随）         |
| `drawEllipse(options)` | `"ellipse"` | 三点：圆心 → 长半轴点 → 短半轴点                   |

### 3.4 停止 / 清除 / 清理

| 方法             | 作用                                                     |
| ---------------- | -------------------------------------------------------- |
| `stopDraw()`     | 停止当前绘制，**删除未完成的实体**（作废），退出绘制状态 |
| `clearDrawing()` | 清除正在绘制的对象（已画部分），**保持绘制状态**重新画   |
| `clear()`        | 清空全部：所有实体 + 绘制/编辑状态 + 事件监听器          |

### 3.5 编辑方法

| 方法                  | 作用                                                          |
| --------------------- | ------------------------------------------------------------- |
| `startEditing(shape)` | 开始编辑：显示可拖拽顶点、切换编辑样式、触发 `editStart` 事件 |
| `stopEditing()`       | 停止编辑：隐藏顶点、恢复样式、触发 `editStop` 事件            |

### 3.6 事件系统

增删点事件返回变更后的 `{ id, positions, type }`，使用 `_shapeResult` 统一组装。绘制增点覆盖六种图形；点单击即完成，无绘制撤销点阶段。预置坐标、批量清空、取消不逐点通知；无效点击、重复点和空撤销不通知。矩形有两个对角点时仍返回推导的四角坐标。

编辑增删仅适用于线／多边形，新增在插入时通知，后续拖拽松手仍通知 `editMovePoint`；删除保留原有 `editMovePoint`，随后通知 `editRemovePoint`。删除入口校验索引和最少点数（线 2、多边形 3），未实际删除时不通知。

```js
draw.on(eventName, callback); // 注册监听，支持链式
draw.off(eventName, callback); // 移除监听（不传 callback 清空该事件）
draw.emit(eventName, data); // 触发事件（内部使用）
```

| 事件              | 触发时机                                                 | 回调数据                  |
| ----------------- | -------------------------------------------------------- | ------------------------- |
| `drawStart`       | 绘制初始化完成（尚未点击地图）；预置坐标路径在完成前触发 | `{ id, positions, type }` |
| `drawAddPoint`    | 绘制时有效加点后（最后一点先于 drawEnd）                 | `{ id, positions, type }` |
| `drawRemovePoint` | 绘制时右键撤销或双击首点实际回退后                       | `{ id, positions, type }` |
| `editAddPoint`    | 线／多边形按下中间点插入新顶点后                         | `{ id, positions, type }` |
| `editRemovePoint` | 线／多边形成功删除顶点并更新辅助点后                     | `{ id, positions, type }` |
| `drawEnd`         | 图形成功完成并清理绘制状态后，先于完成回调和自动编辑     | `{ id, positions, type }` |
| `editStart`       | 激活 / 进入某个实体的编辑（首次进入或切换）              | `{ id, positions, type }` |
| `editMovePoint`   | 编辑拖拽点**松手**（编辑完点）                           | `{ id, positions, type }` |
| `editStop`        | 结束编辑（空白退出 / 切换 / 删除编辑中实体）             | `{ id, positions, type }` |
| `removeGraphic`   | 删除单个实体（右键菜单“删除”）                           | `{ id, positions, type }` |

> `drawStart.positions` 为开始时的坐标快照，交互绘制通常为 `[]`，预置坐标绘制为初始坐标；点、矩形提前分配正式实体 id，确保开始与结束的 id 一致。其他事件的 `positions` 为内部坐标数组的**实时引用**（矩形返回推导的 4 角点）。
>
> 两个绘制事件覆盖六种图形的 `startDraw` 和直接绘制方法，不受 `enableEdit` / `autoEdit` 限制。取消绘制、清空图层或点数不足作废不触发 `drawEnd`；`clearDrawing()` 保持当前绘制，不重复触发 `drawStart`。监听需在启动绘制前注册。

## 五、新增绘制类型的扩展步骤

以新增"三角形 `triangle`"为例：

1. **新建模块** `js/modules/drawTriangle.js`，默认导出 `(ctx, options)`：
   ```js
   export default function drawTriangle(ctx, { id, style = {}, success }) {
     ctx.stopEditing();          // 避坑：先清理遗留 handler
     const shape = { type: "triangle", points: [], mainEntity: null, ... };
     ctx.activeShape = shape;
     // ... 创建实体、注册 MOUSE_MOVE / LEFT_CLICK / RIGHT_CLICK / LEFT_DOUBLE_CLICK ...
     // 完成时调用 ctx.completeShape(shape)
   }
   ```
2. **`js/drawTool.js`**：
   - `import drawTriangleModule from "./modules/drawTriangle.js";`
   - 新增委托方法 `drawTriangle(options) { drawTriangleModule(this, options); }`
   - `startDraw` 分发加分支：
     ```js
     if (type === "triangle") {
       if (typeof success === "function") {
         this.drawTriangle({ style, success, id });
         return;
       }
       return new Promise((resolve) =>
         this.drawTriangle({ style, success: resolve, id }),
       );
     }
     ```
3. **`js/gui.js`** 加按钮：`drawTriangle: () => startDraw(draw, "triangle")`（`drawActions.js` 已统一 type 分发，无需改）。
4. **编辑复用**：顶点模型直接走 `startEditing` 通用拖拽；若需保持形状（如矩形对角联动），在 shape 上挂 `updatePoint(index, lonlat)`。

## 六、避坑记录（开发中踩过的坑）

| 坑                                | 规避方式                                                                                         |
| --------------------------------- | ------------------------------------------------------------------------------------------------ |
| 旧 handler 泄漏导致多实体互相干扰 | 每个绘制模块开头调用 `ctx.stopEditing()`（内部 destroy 旧 handler）                              |
| 预览实体误用 points 数组          | 预览实体（虚线/预览面）一律用**自定义 positions 回调**（`tempPoint`）                            |
| 实体更新需手动刷新                | 主实体 positions/hierarchy/属性统一用 `CallbackProperty` **引用** `shape.points`，改数组自动更新 |
| 矩形编辑变四边形                  | 矩形数据保持 **2 对角点**，`updatePoint` 联动更新边界，4 角推导                                  |
| 矩形整体拖拽报错/角点错位         | `points`(2) 与 `pointsEntity`(4) 数量不一致 → `_updateVertexEntities` 对矩形按对角点推导 4 角    |
| 双击画第一个点误结束              | 记录 `firstPointTime`，500ms 内双击回退多加的点、不结束                                          |
| id 冲突抛异常                     | 创建前 `viewer.entities.getById(id)` 检查，`removeGraphic`/`removeById` 覆盖                     |
| polygon outline 贴地失效          | 显式 `height: 0`（贴地不支持 outline）                                                           |
| height + zIndex 冲突警告          | 有 height 的几何体不设置 zIndex                                                                  |
| 点的可拖拽编辑失效                | 画点把 `mainEntity` 放入 `pointsEntity`（作为唯一可拖拽点），隐藏/恢复样式时跳过 mainEntity      |
