操作用例指南
  1. 右侧选择 Promise、回调或类型方法，设置样式后绘制六类图形。ID 留空自动生成；同 ID 绘制会删除旧图形，取消不恢复。
  2. 点单击完成；线/多边形单击加点、右键撤销、双击完成；矩形/圆点两次；椭圆依次选中心、长轴点、短轴点。
  3. 停止绘制、切换类型、清空、销毁会取消 Promise；重新绘制只清除控制点，保留会话。线不足两点或多边形不足三点双击会作废。
  4. 点击实体、右键菜单或面板进入编辑。拖动顶点调整，橙色手柄整体平移；半透明手柄拖动插点，右键顶点删除。两点线段插点手柄位于四分之一处。
  5. 运行时关闭编辑会立即退出；自动编辑只对交互绘制生效。圆/椭圆中心用于平移，轴端用于改尺寸。
  6. 回显须先停止绘制和编辑。单个/六类样例可反复追加；JSON 中已有 ID 会拒绝，不覆盖。往返用例：导出 → 清空图形 → 从 JSON 追加。
  7. 观察全部十类事件与完成快照。关闭日志仅停止显示；off/on 按钮演示解除与恢复监听。编辑后再查询可对比完成时的快照。
  8. 选择外部共享图层后重建：黄色点属于业务；clear/destroy 后仍保留。再次重建由演示页主动移除旧业务图层。销毁幂等，必须重建才能继续操作。
  9. 非法坐标、退化图形、非法样式及重复 ID 用例验证整批拒绝。右下角菜单验证边界定位；顶点删除菜单需有效索引及足够点数。
  10. 可开启按需渲染后重复绘制、编辑、显隐。快速拖拽后的相机漂移仍是已知待排查问题；圆/椭圆仅用于局部近似绘制。
