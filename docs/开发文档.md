# 绘制工具开发文档（DrawTool）

基于 Cesium 的图形绘制工具库，支持绘制**线、点、矩形、多边形、圆、椭圆**，并提供编辑（顶点拖拽 / 整体拖拽）、右键菜单、事件监听、停止/清除绘制等能力。

---

## 一、目录结构

```
cesium_draw/
├── index.html                 # 页面入口（加载 Cesium、初始化 Draw、创建 GUI 面板）
├── js/
│   ├── drawTool.js            # 核心类 DrawTool：公共方法、事件系统、绘制分发、编辑、右键菜单、清理

│   ├── gui.js                 # lil-gui 面板：绘制按钮 + 停止/重新绘制/清空图层
│   └── modules/               # 各绘制类型独立模块
│       ├── drawLine.js        # 画线
│       ├── drawPoint.js       # 画点
│       ├── drawRect.js        # 画矩形（对角点模型 + 联动编辑保持矩形）
│       ├── drawPolygon.js     # 画多边形（顶点模型 + 预览面）
│       ├── drawCircle.js      # 画圆（圆心 + 半径点）

└── libs/
    ├── Cesium/                # 离线 Cesium
    └── lil-gui.js             # 离线 lil-gui（ES Module）
```

## 二、架构分层

```
┌─────────────┐   type    ┌──────────────┐   调用    ┌──────────────────┐
│  gui.js     │ ────────▶ │ drawActions  │ ───────▶ │ drawTool.js (Draw)│
│ （按钮层）   │  "line"等  │ （动作层）    │ startDraw │ （核心类）         │
└─────────────┘           └──────────────┘           │   ├ 公共工具方法    │
                                                     │   ├ 事件系统        │
                                                     │   ├ 绘制分发 startDraw│
                                                     │   └ 编辑/菜单/清理   │
                                                     └────────┬─────────┘
                                                              │ drawLineModule(this, options)
                                                     ┌────────▼─────────┐
                                                     │ js/modules/*.js  │
                                                     │ （各类型绘制模块） │
                                                     └──────────────────┘
```

- **绘制模块模式**：每个模块默认导出一个 `(ctx, options)` 函数，`ctx` 为 DrawTool 实例（this），通过 `ctx` 调用公共方法，主类保持精简。
- **shape 数据模型**：每次绘制创建一个独立的 `shape` 对象，结构：
  ```js
  {
    type: "line" | "point" | "rect" | "polygon" | "circle" | "ellipse",
    id,               // 自定义实体 id（可选）
    controlPoints,    // 坐标数组（线/多边形=顶点；矩形=2对角点；圆=圆心+半径点；椭圆=圆心+长轴点+短轴点）
    mainEntity,       // 主实体（polyline / polygon / ellipse / point）
    previewEntity,       // 预览实体（虚线/预览面，部分模块有）
    previewLineEntity,   // 预览虚线（多边形专用）
    controlPointEntities,     // 顶点实体数组（编辑拖拽用）
    previewPosition, // 经纬度预览点，各类型统一为 [lon, lat] 或 null
    midpointEntities, // 线、多边形的插点手柄
    translationHandleEntity, // 橙色平移手柄
    style,            // { lineWidth, color, pointSize, clampToGround }
    firstPointTime,   // 第一个点点击时间（线/多边形，识别"双击画第一个点"）
    updatePoint,      // 可选：矩形等特殊形状的顶点联动更新函数
  }
  ```

## 三、核心类 API（js/drawTool.js）

### 图层与实体所有权

`config.dataSource` 可传入已由业务侧挂载的 `Cesium.CustomDataSource`；省略时自动创建并挂载默认图层。公开属性 `dataSource` 提供图层管理，`ready` 为默认挂载的 Promise（外部图层直接返回已解决的 Promise，不代替业务挂载）。

全部实体创建、查询与删除通过内部 `_ownedEntities` 适配器处理；适配器以 Set 跟踪当前实例创建的实体，包括预览、标签及编辑辅助点。`clear()` 仅删除该集合，逐个发送已完成图形的 `removeGraphic`，不删除共享图层中的其他业务对象，也不移除图层。同 ID 的外部实体禁止覆盖。新增模块不得再直接操作 `viewer.entities`。

### 单实体删除接口

`removeGraphic(shape)` 的参数兼容字符串 ID 和内部 shape 对象，替代旧方法名 `removeShape`。字符串通过 `this.shapes.find(item => item.mainEntity.id === shape)` 解析，仅匹配当前实例已登记的图形；不直接按 ID 删除 Cesium 图层实体，因此不会删除共享图层中的外部对象。对象参数必须是内部 shape，不是 `addGraphic` / `getGraphic` 返回的快照或 `Cesium.Entity`。

ID 未找到或参数为 `null` / `undefined` 时直接返回，不触发事件；方法返回值为 `undefined`。正常删除沿用原流程：若为当前编辑对象先 `stopEditing()` → 清理主实体、临时实体和编辑辅助实体 → 从 `shapes` 移除 → 发出 `removeGraphic`。删除编辑对象时 `editStop` 先于 `removeGraphic`，删除操作不受 `enableEdit` 限制。

### 存储与静默加载管线

公开接口 `getGraphic(id)` / `getGraphics()` 导出 `{ id, type, positions, style }` 快照，`addGraphic(data)` / `loadGraphics(dataList)` 同步返回新增快照。坐标和样式复制，不更改原事件载荷；业务在 `drawEnd`、`editStop` 查询快照保存。详细输入格式见使用文档。回显省略 `id` 或传入 `undefined` 时由 `_normalizeGraphic` 调用 `Cesium.createGuid()` 生成，返回及导出保留生成值，不修改输入；显式非法 ID 与 ID 冲突仍拒绝。

加载流程：检查空闲状态 → `_normalizeGraphic` 全量校验并复制 → 检查已有及批内 ID → `types[type].create` 创建 Entity → `_registerShape` 固定属性并登记 → 启用空闲拾取。

- 六个模块的具名 Entity 工厂 同时用于交互与回显，不启动 handler，也不调用 `completeShape`。
- `getRectangleCorners` 和 `updatePoint` 统一矩形四角与对角点模型；圆、椭圆共用控制点距离和 CallbackProperty 算法。
- `_registerShape` 释放绘制辅助点、固定动态属性并登记；`completeShape` 继续承担 `drawEnd` → `success` → 可选自动编辑。回显不经过此交互完成流程。
- 主实体、顶点和中心点全部经 `_ownedEntities` 跟踪。加载前记录所有权快照和 shapes 长度；创建异常时删除新增实体、撤销本批登记，并清理本批新建的空闲 handler。
- `_loadingGraphics` 阻止加载重入；绘制或编辑期间直接拒绝加载，不隐式停止操作。
- 加载不覆盖 ID、不自动清空、不发绘制或编辑开始事件；后续编辑、菜单和删除沿用原逻辑。`clear()` 的删除事件与图层所有权契约保持不变。

新增类型时，除交互分发外还须扩展加载校验、`types` 注册表及往返测试。

验证命令：`node tests/graphics.test.mjs`。测试加载仓库真实 Cesium 数据模型，以最小鼠标 handler / DOM 桩验证六种图形往返、静默事件、坐标联动、编辑增删、校验、回滚和共享图层隔离；它不替代浏览器 WebGL 渲染验证。

### 3.1 构造函数

```js
new Draw(viewer, config);
```

| 参数                | 类型                    | 说明                                                                                                                   |
| ------------------- | ----------------------- | ---------------------------------------------------------------------------------------------------------------------- |
| `viewer`            | Cesium.Viewer           | 必传                                                                                                                   |
| `config.dataSource` | Cesium.CustomDataSource | 可选外部图层，挂载/移除由业务负责                                                                                      |
| `config.style`      | object                  | 默认样式 `{ lineWidth, color, pointSize, clampToGround }`（兼容旧写法直接传 `{ lineWidth, ... }`）                     |
| `config.enableEdit` | boolean                 | 是否支持编辑，默认 `true`；为 `false` 时禁用所有编辑入口（点击实体 / 右键「开始编辑」/ 自动编辑），`autoEdit` 随之失效 |
| `config.autoEdit`   | boolean                 | 绘制完成后是否自动进入编辑，默认 `true`（仅在 `enableEdit` 为 `true` 时生效）                                          |

### 3.2 绘制入口 `startDraw(options)`

支持**回调**与**异步（Promise）**两种调用方式：

```js
// 回调方式
draw.startDraw({
  id: "line1",            // 可选：自定义实体 id
  type: "line",           // 必传：line / point / rect / polygon / circle / ellipse
  style: { color: "#0092ff" },  // 可选：本次绘制样式，覆盖默认
  success: (result) => { ... }, // 可选：绘制完成回调
});

// 异步方式
try {
  const result = await draw.startDraw({ type: "rect" });
  console.log(result); // { id, positions, type } 快照
} catch (error) {
  if (error.name !== "AbortError") throw error;
}
```

> 传了 `success` 走回调（返回 undefined，取消不调用）；不传返回 Promise。成功 resolve 快照，停止、切换、清空、销毁和点数不足作废 reject `AbortError`。初始化失败保留原始错误。

### 3.3 各类型绘制方法（内部由 startDraw 分发）

| 方法                   | type        | 交互                                               |
| ---------------------- | ----------- | -------------------------------------------------- |
| `drawLine(options)`    | `"line"`    | 单击加点、右键删点（虚线实时重绘）、双击结束       |
| `drawPoint(options)`   | `"point"`   | 单击放置点即完成（鼠标移动有预览点）               |
| `drawRect(options)`    | `"rect"`    | 两点对角：第一点起点、第二点对角，预览矩形实时跟随 |
| `drawPolygon(options)` | `"polygon"` | 单击加点、预览面实时闭合、右键删点、双击结束       |
| `drawCircle(options)`  | `"circle"`  | 第一点圆心、第二点半径点（预览圆实时跟随）         |
| `drawEllipse(options)` | `"ellipse"` | 三点：圆心 → 长半轴点 → 短半轴点                   |

### 3.4 停止 / 清除 / 清理

| 方法                                      | 作用                                                         |
| ----------------------------------------- | ------------------------------------------------------------ |
| `stopDraw()`                              | 停止当前绘制，**删除未完成的实体**（作废），退出绘制状态     |
| `clearDrawing()`                          | 清除正在绘制的对象（已画部分），**保持绘制状态**重新画       |
| `clear()`                                 | 清空本工具实体与交互，保留图层和业务事件监听器，可复用       |
| `destroy()`                               | 完整释放实例、自建图层与监听器；外部图层保留，幂等且不可复用 |
| `getGraphic(id)` / `getGraphics()`        | 查询单个/全部独立数据快照                                    |
| `addGraphic(data)` / `loadGraphics(list)` | 空闲时静默追加；校验、冲突、回滚规则一致                     |

### 3.5 编辑方法

| 方法                  | 作用                                                          |
| --------------------- | ------------------------------------------------------------- |
| `startEditing(shape)` | 开始编辑：显示可拖拽顶点、切换编辑样式、触发 `editStart` 事件 |
| `stopEditing()`       | 停止编辑：释放手柄、固定属性、恢复相机，再触发 `editStop`     |
| `enableEdit = false`  | 立即结束现有编辑，禁用所有编辑入口                            |

### 3.6 事件系统

增删点事件返回变更后的 `{ id, positions, type }`，使用 `_buildGraphicResult` 统一组装。绘制增点覆盖六种图形；点单击即完成，无绘制撤销点阶段。预置坐标、批量清空、取消不逐点通知；无效点击、重复点和空撤销不通知。矩形有两个对角点时仍返回推导的四角坐标。

编辑增删仅适用于线／多边形，新增在插入时通知，后续拖拽松手仍通知 `editMovePoint`；删除保留原有 `editMovePoint`，随后通知 `editRemovePoint`。删除入口校验索引和最少点数（线 2、多边形 3），未实际删除时不通知。

```js
draw.on(eventName, callback); // 注册监听，支持链式
draw.off(eventName, callback); // 移除监听（不传 callback 清空该事件）
draw.emit(eventName, data); // 触发事件（内部使用）
```

| 事件              | 触发时机                                                                  | 回调数据                  |
| ----------------- | ------------------------------------------------------------------------- | ------------------------- |
| `drawStart`       | 绘制初始化完成（尚未点击地图）；预置坐标路径在完成前触发                  | `{ id, positions, type }` |
| `drawAddPoint`    | 绘制时有效加点后（最后一点先于 drawEnd）                                  | `{ id, positions, type }` |
| `drawRemovePoint` | 绘制时右键撤销或双击首点实际回退后                                        | `{ id, positions, type }` |
| `editAddPoint`    | 线／多边形按下中间点插入新顶点后                                          | `{ id, positions, type }` |
| `editRemovePoint` | 线／多边形成功删除顶点并更新辅助点后                                      | `{ id, positions, type }` |
| `drawEnd`         | 图形成功完成并清理绘制状态后，先于完成回调和自动编辑                      | `{ id, positions, type }` |
| `editStart`       | 编辑状态、手柄及 handler 全部准备完成后                                   | `{ id, positions, type }` |
| `editMovePoint`   | 编辑拖拽点**松手**（编辑完点）                                            | `{ id, positions, type }` |
| `editStop`        | 编辑状态清空、手柄释放、相机恢复后                                        | `{ id, positions, type }` |
| `removeGraphic`   | `removeGraphic(id或shape)` / 右键菜单删除；`clear()` 对已完成图形逐个触发 | `{ id, positions, type }` |

> `drawStart.positions` 为开始时的坐标快照，交互绘制通常为 `[]`，预置坐标绘制为初始坐标；点、矩形提前分配正式实体 id，确保开始与结束的 id 一致。所有其他事件与完成结果也返回独立坐标快照，每个监听器的数组独立；最新数据通过 `getGraphic(id)` 获取（矩形返回推导的 4 角点）。
>
> 两个绘制事件覆盖六种图形的 `startDraw` 和直接绘制方法，不受 `enableEdit` / `autoEdit` 限制。取消绘制、清空图层或点数不足作废不触发 `drawEnd`；`clearDrawing()` 保持当前绘制，不重复触发 `drawStart`。监听需在启动绘制前注册。

## 五、新增绘制类型的扩展步骤

以新增"三角形 `triangle`"为例：

1. 新建模块，默认导出交互函数，具名导出 `createTriangleEntity(ctx, shape)`。工厂只创建 Entity，不注册交互、不发事件。
2. 核心 `types` 注册 `{ draw: drawTriangleModule, create: createTriangleEntity }`，扩展 `_normalizeGraphic` 点数及几何规则、`_canAddPoint` 完成点数。无需复制 Promise 分支。
3. 交互使用 `_createDrawingShape` 初始化模型，`_createInteractionHandler` 注册鼠标事件。有效加点先校验，修改后发事件，再检查 `ctx.drawingShape === shape` 才继续完成。
4. 完成调用 `completeShape(shape)`，取消调用 `stopDraw()`，不得直接清空会话或调用完整 `destroy()`。
5. 特殊形状提供 `shape.updatePoint(index, lonlat)`，只更新控制点；核心 `_moveControlPoint` 校验、回退及同步手柄。
6. 添加 GUI 按钮、往返及交互回归测试、文档；新增对外委托方法也必须走 `_startDrawing`。

## 六、避坑记录（开发中踩过的坑）

| 坑                        | 规避方式                                                                                              |
| ------------------------- | ----------------------------------------------------------------------------------------------------- |
| 旧绘制残留                | `_startDrawing` 统一取消旧会话，模块不重复处理切换                                                    |
| 预览实体误用 points 数组  | 预览实体（虚线/预览面）一律用**自定义 positions 回调**（`previewPosition`）                           |
| 动态属性与按需渲染        | 回调读取当前 controlPoints；`_setDynamic` 在编辑/空闲间切换，工具更新后 requestRender                 |
| 矩形编辑变四边形          | 矩形数据保持 **2 对角点**，`updatePoint` 联动更新边界，4 角推导                                       |
| 矩形整体拖拽报错/角点错位 | `points`(2) 与 `controlPointEntities`(4) 数量不一致 → `_updateVertexEntities` 对矩形按对角点推导 4 角 |
| 双击画第一个点误结束      | 记录 `firstPointTime`，500ms 内双击回退多加的点、不结束                                               |
| ID 冲突与所有权           | `_ownedEntities` 禁止覆盖外部对象；交互开始时覆盖本工具旧图形，回显始终拒绝冲突                       |
| polygon outline 贴地失效  | 显式 `height: 0`（贴地不支持 outline）                                                                |
| height + zIndex 冲突警告  | 有 height 的几何体不设置 zIndex                                                                       |
| 点的可拖拽编辑失效        | 画点把 `mainEntity` 放入 `controlPointEntities`（作为唯一可拖拽点），隐藏/恢复样式时跳过 mainEntity   |

## 七、内部命名及生命周期约束

- 默认导出类名为 `DrawTool`（调用方仍可 `import Draw`）。内部使用 `defaultStyle`、`drawingShape`、`editingShape`、`interactionHandler`、`_ownedEntities`；`editing` 由 editingShape 派生，不再独立维护。
- `points` → `controlPoints`，`pointsEntity` → `controlPointEntities`，`centerEntity` → `translationHandleEntity`，`midpointsEntity` → `midpointEntities`。这些是内部字段，不提供旧名别名；业务使用公开快照 API。
- `_shapeResult` → `_buildGraphicResult`，`_calcCenter` → `_getTranslationCenter`，`_midOf` → `_getMidpoint`；各模块 `createXxxGeometry` 改为 Entity 工厂名称。
- `_session` 保存一次绘制的回调与 reject；`_revision` 防止事件重入后旧流程覆盖新会话。回调和事件错误逐个捕获，不阻断后续完成及监听。
- `clear()` 期间禁止新绘制/加载，清理结束再逐个发删除事件；`destroy()` 先标记已销毁，杜绝监听器重建资源。
- `_destroyInteractionHandler()` 仅清理内部交互、光标及相机；公开 `destroy()` 完整释放。Viewer 双击操作采用 WeakMap 计数，最后一个工具释放时恢复，且不覆盖业务后来设置的新操作。
- 自建图层异步挂载后检查销毁标记；外部图层只清理本工具拥有的实体，不负责挂载或移除。
- `_setDynamic` 保存绑定，空闲时赋常量、编辑时恢复。点主实体与控制点共用，不能随手柄释放而删除。
- 圆/椭圆中心控制点与橙色平移手柄重合，两种拾取结果统一进入整体平移；轴端控制点仍用于调整半径或半轴。
- 中点及平移处理经度环绕、拒绝纬度越界；圆/椭圆保留局部近似。不保证极区、全球大范围精确测绘或多边形拓扑合法性。
- 菜单样式采用 `:where()`，维持 body 挂载和原 CSS 类；延迟点击监听可取消，视口边缘定位修正。样式覆盖与接口迁移说明见使用文档。
