# 绘制工具使用文档（DrawTool）

基于 Cesium 的地图图形绘制工具，支持绘制**线、点、矩形、多边形、圆、椭圆**，画完可编辑（拖拽顶点 / 整体移动）、右键菜单操作、事件监听。

---

## 数据保存与回显

| API                             | 返回值                                              |
| ------------------------------- | --------------------------------------------------- |
| `draw.getGraphic(id)`           | 已完成图形快照，未找到返回 `null`                   |
| `draw.getGraphics()`            | 所有已完成图形快照数组                              |
| `draw.addGraphic(data)`         | 同步追加一个历史图形，返回快照                      |
| `draw.loadGraphics(dataList)`   | 同步追加一批历史图形，返回快照数组；空数组返回 `[]` |
| `draw.removeGraphic(id或shape)` | 按字符串 ID 或内部 shape 对象删除单个图形           |

```js
const record = {
  id: "saved-circle",
  type: "circle",
  positions: [
    [110, 30],
    [111, 30],
  ],
  style: { color: "red", lineWidth: 2, pointSize: 10, clampToGround: false },
};
draw.addGraphic(record);
const json = JSON.stringify(draw.getGraphics()); // 由业务自行持久化
// 在另一个空闲 Draw 实例中：otherDraw.loadGraphics(JSON.parse(json));
draw.on("drawEnd", (data) => {
  const snapshot = draw.getGraphic(data.id);
  // 将 snapshot 交给业务保存接口
});
draw.on("editStop", (data) => {
  const snapshot = draw.getGraphic(data.id);
  // 将 snapshot 交给业务更新接口
});
```

### 删除单个图形

```js
const graphic = draw.addGraphic({ type: "point", positions: [[110, 30]] });
draw.removeGraphic(graphic.id); // 按字符串 ID 删除，也适用于自动生成的 ID
// 兼容传入 draw.shapes 中的内部 shape 对象；不要传入导出快照或 Cesium.Entity
```

`removeGraphic`（原名 `removeShape`）支持字符串 ID 和内部 shape 对象，返回值为 `undefined`。按 ID 仅查找当前工具的已完成图形，不删除共享图层中的其他业务实体。ID 不存在（包括已删除的 ID），或传入 `null` / `undefined` 时直接返回，不触发删除事件。

成功删除会清理主实体、辅助实体及内部登记，并触发 `removeGraphic` 事件，载荷为 `{ id, positions, type }`。若删除的是正在编辑的图形，会先退出编辑并触发 `editStop`，再触发删除事件；不受 `enableEdit` 开关限制。删除全部图形仍使用 `draw.clear()`。

### 坐标和样式约定

每个点为严格的二维 `[经度, 纬度]`，数字必须有限，经度在 [-180, 180]、纬度在 [-90, 90]。`id` 可省略或设为 `undefined`，内部通过 `Cesium.createGuid()` 自动生成；显式提供时必须为非空字符串（`null`、空白和数字仍拒绝）。生成的 ID 包含在回显返回值和后续导出中，不写回输入对象。保存时请保留该 ID，否则重复加载无 ID 数据会追加新图形。页面可调用 `drawDemo.addGraphic({ type: "point", positions: [[110, 30]] })`。

| type      | positions                                                                                    |
| --------- | -------------------------------------------------------------------------------------------- |
| `point`   | 1 个点                                                                                       |
| `line`    | 至少 2 个顶点                                                                                |
| `polygon` | 至少 3 个顶点，不重复首点                                                                    |
| `rect`    | 4 个有序角点：`[[x1,y1],[x2,y1],[x2,y2],[x1,y2]]`；也接受 2 个对角点，导出总为四角；宽高非零 |
| `circle`  | 圆心、半径控制点；半径大于零                                                                 |
| `ellipse` | 圆心、长半轴控制点、短半轴控制点；两半轴大于零，短半轴不大于长半轴                           |

圆和椭圆保存控制点，不保存轮廓采样点。矩形回显恢复四角联动。`style` 可省略或仅提供部分字段，未提供字段取实例默认值；颜色须为 Cesium 支持的 CSS 颜色，线宽和点大小须为有限正数，贴地须为布尔值。点图形当前不贴地，导出的 `clampToGround` 固定为 `false`；其他样式按图形支持范围生效。退化矩形、零半径和非法半轴数据会拒绝回显。

### 生命周期与失败处理

- 四个 API 的数据不暴露内部可变引用；修改输入或导出结果不会修改地图实体。
- 回显只追加，不触发 `drawStart`、`drawAddPoint`、`drawEnd`、`success`、`editStart`，不受 `autoEdit` 影响；原事件仍为 `{ id, positions, type }`。
- 回显后可点击或右键编辑、增删线与多边形顶点、拖动控制点及删除；`enableEdit=false` 时仍可删除。
- 绘制或编辑中拒绝加载，需业务先调用 `stopDraw()` / `stopEditing()`。
- 已有图形、共享图层实体或批内 ID 冲突均抛错，不覆盖。批量先完成全部校验；创建失败时撤销本批实体与登记，不影响之前的图形。
- 全量替换由业务显式调用 `clear()`；它仍触发每个已完成图形的 `removeGraphic`。若监听该事件删除数据库记录，业务需区分界面重载与真实删除。
- 默认图层自动挂载，外部图层由业务管理；`clear()` 保留其他业务实体和图层本身。不要直接删除实体集合来代替 `clear()`。
- 不内置数据库、网络请求或 localStorage；页面提供 `drawDemo.exportJSON()` / `drawDemo.loadJSON(text)` 按需调用示例。

## 一、快速开始

### 1. 引入

页面需通过本地静态服务器访问（ES Module 不支持 `file://` 直接打开），例如：

```bash
# 项目根目录启动静态服务
http-server
# 浏览器访问 http://localhost:8080
```

`index.html` 已引入离线 Cesium 与绘制工具模块。

### 2. 初始化

```js
import Draw from "./js/drawTool.js";
import initGui from "./js/gui.js";

// 创建 Cesium Viewer（省略配置）
const viewer = new Cesium.Viewer("map", { ... });

// 创建绘制工具实例
const draw = new Draw(viewer, {
  enabledRightMenu: true,                    // 可选：是否启用右键菜单，默认 true；false 时禁用所有场景的右键菜单
  enableEdit: true,                        // 可选：是否支持编辑，默认 true；false 时禁用所有编辑入口
  autoEdit: true,                          // 可选：绘制完自动进入编辑，默认 true
  isContinued: false,                      // 可选：是否连续绘制，默认 false；true 时绘制完成后自动开始同类型下一次绘制
  style: { lineWidth: 2, color: "#0092ff", pointSize: 10 }, // 可选：默认样式
});

// 创建 lil-gui 面板（右上角按钮组）
initGui(draw, viewer);
```

## 二、绘制操作

### 方式一：面板按钮

面板默认提供：**点 / 线 / 矩形 / 多边形 / 圆 / 椭圆 / 停止绘制 / 重新绘制 / 清空图层**。

点击对应按钮后，在地图上按交互规则绘制。

### 方式二：代码调用

```js
// 回调方式（传 success）
draw.startDraw({
  type: "line",
  style: { color: "#ff0000" }, // 可选，覆盖默认样式
  id: "myLine", // 可选，自定义实体 id
  success: (result) => {
    console.log(result.id, result.positions, result.type);
  },
});

// 异步方式（不传 success，返回 Promise）
// 写法一：async / await
try {
  const result = await draw.startDraw({ type: "rect" });
  console.log(result); // { id, positions, type } 快照
} catch (error) {
  if (error.name !== "AbortError") throw error;
}

// 写法二：.then()
draw
  .startDraw({ type: "polygon" })
  .then(console.log)
  .catch((error) => {
    if (error.name !== "AbortError") console.error(error);
  });
```

### 各类型的绘制交互

| 类型       | 交互步骤                                   | 完成方式       |
| ---------- | ------------------------------------------ | -------------- |
| **线**     | 单击加点；右键删除最后一点                 | 双击结束       |
| **点**     | 鼠标移动有预览点                           | 单击放置即完成 |
| **矩形**   | 第一点定起点，第二点定对角（预览实时跟随） | 第二点点击完成 |
| **多边形** | 单击加点（预览面实时闭合）；右键删点       | 双击闭合结束   |
| **圆**     | 第一点圆心，第二点半径点（预览实时跟随）   | 第二点点击完成 |
| **椭圆**   | 三点：圆心 → 长半轴点 → 短半轴点           | 第三点点击完成 |

> 线/多边形用右键删点，矩形/圆/椭圆用右键回退参数点；点单击即完成，没有绘制撤销阶段。

### 停止 / 重新绘制

| 按钮         | 作用                                               |
| ------------ | -------------------------------------------------- |
| **停止绘制** | 停止当前绘制并**删除未完成的实体**（不保留半成品） |
| **重新绘制** | 清除当前已画的半成品，**保持绘制状态**原地重画     |
| **清空图层** | 清空地图上**所有**已画实体                         |

代码：`draw.stopDraw()` / `draw.clearDrawing()` / `draw.clear()`

## 三、编辑操作

> 是否支持编辑由 `enableEdit` 控制（默认 `true`）。设为 `false` 时，点击实体、右键菜单「开始编辑」、绘制后自动编辑（`autoEdit`）全部禁用，仅保留右键「删除」。

绘制完成后默认自动进入编辑（`autoEdit: true`），也可点击实体或右键菜单进入。

| 操作                 | 行为                                                   |
| -------------------- | ------------------------------------------------------ |
| 按住**顶点**拖动     | 修改该顶点位置（矩形对角联动，保持矩形；其余独立拖拽） |
| 拖动**橙色中心手柄** | **整体移动**整个图形（线/面/圆/椭圆）                  |
| 点击空白处           | 退出编辑                                               |
| 点击其他实体         | 切换编辑到该实体                                       |
| 右键实体             | 弹出菜单：**开始编辑 / 停止编辑 / 删除**               |

> 悬停在线/面上会显示「左键点击进行编辑，右键菜单」提示。

## 四、获取绘制结果

### 1. 绘制完成回调 / Promise

`startDraw` 支持两种接收结果的方式，二选一：

| 方式     | 用法                               | 返回值                             |
| -------- | ---------------------------------- | ---------------------------------- |
| **回调** | 传 `success` 回调函数              | `undefined`（结果走回调）          |
| **异步** | 不传 `success`，方法返回 `Promise` | `Promise<{ id, positions, type }>` |

```js
// 回调方式
draw.startDraw({ type: "line", success: (r) => console.log(r) });

// 异步方式（await）
try {
  const r = await draw.startDraw({ type: "polygon" });
  console.log(r); // 坐标为完成时快照
} catch (error) {
  if (error.name !== "AbortError") throw error;
}

// 异步方式（.then）
draw
  .startDraw({ type: "circle" })
  .then(console.log)
  .catch((error) => {
    if (error.name !== "AbortError") console.error(error);
  });
```

### 2. 事件监听（绘制、编辑与删除）

请在启动绘制前注册监听。`drawStart` 在绘制初始化完成时触发，`drawEnd` 在成功完成时触发（先于 `success` 和自动编辑），不受编辑开关影响。取消或作废不触发 `drawEnd`，原地重新绘制不重复触发 `drawStart`。

```js
// 进入绘制状态：交互绘制 positions 为 []，id 与完成后的实体一致
// 直接传入预置坐标时，positions 为初始坐标快照
draw.on("drawStart", (data) => {
  console.log("开始绘制", data); // { id, positions, type }
});

draw.on("drawAddPoint", (data) => {
  console.log("绘制新增了点", data); // { id, positions, type }
});

draw.on("drawRemovePoint", (data) => {
  console.log("绘制删除了点", data); // { id, positions, type }
});

draw.on("drawEnd", (data) => {
  console.log("结束绘制", data); // { id, positions, type }
});

// 进入某个实体的编辑时触发（画完自动进入 / 点击激活 / 右键开始编辑）
draw.on("editStart", (data) => {
  console.log("开始编辑", data); // { id, positions, type }
});

// 按下线或多边形的中间点，插入新顶点后触发
draw.on("editAddPoint", (data) => {
  console.log("编辑新增了点", data); // { id, positions, type }
});

// 通过右键菜单成功删除顶点后触发
draw.on("editRemovePoint", (data) => {
  console.log("编辑删除了点", data); // { id, positions, type }
});

// 编辑完一个点（拖拽松手）后触发
draw.on("editMovePoint", (data) => {
  console.log("编辑完点", data); // { id, positions, type }
});

// 结束编辑后触发
draw.on("editStop", (data) => {
  console.log("结束编辑", data); // { id, positions, type }
});

// removeGraphic(id或shape)、右键菜单删除后触发；clear() 对每个已完成图形逐个触发
draw.on("removeGraphic", (data) => {
  console.log("删除实体", data); // { id, positions, type }
});

// 移除监听
draw.off("editMovePoint", handler);
```

> 所有事件及完成结果的 `positions` 都是独立快照，各监听器互不共享坐标数组；编辑后请调用 `getGraphic(id)` 查询最新坐标。矩形返回 4 个角点，圆返回 `[圆心, 半径点]`，椭圆返回 `[圆心, 长轴点, 短轴点]`。

增删点事件返回操作后的坐标。最后一个有效点的 `drawAddPoint` 先于 `drawEnd`；无效点击、重复点及无点可撤销时不触发。线／多边形双击首点导致的实际回退也触发 `drawRemovePoint`。预置坐标加载、清空、取消不逐点触发增删事件。

`editAddPoint` / `editRemovePoint` 仅用于支持增删顶点的线和多边形，需启用编辑。插入后拖拽松手仍触发 `editMovePoint`，删除顶点也保留原有 `editMovePoint` 通知。矩形新增第二个对角点时，`positions` 按现有规则返回推导出的 4 个角点。

## 图层管理

默认创建独立的 `CustomDataSource`，通过 `await draw.ready` 等待默认图层挂载，通过 `draw.dataSource` 访问。实体不再位于 `viewer.entities`，请使用 `draw.dataSource.entities.getById(id)` 查询。

```js
const layer = new Cesium.CustomDataSource("业务绘制图层");
await viewer.dataSources.add(layer); // 外部图层由业务侧挂载，工具不会重复添加
const draw = new Draw(viewer, { dataSource: layer });
layer.show = false; // 同时隐藏图形、预览和编辑辅助点
layer.show = true;
draw.clear(); // 仅清除此工具创建的实体，保留共享图层内其他业务对象
```

同图层中本工具已有图形的同 ID 覆盖行为保持不变；其他业务对象或其他工具实例的同 ID 实体不会被覆盖，而是抛出错误。请为业务绘制分配不冲突的 ID。

移除图层前先调用 `draw.clear()`，再由业务侧调用 `viewer.dataSources.remove(layer)`。不要在工具仍使用时直接销毁图层或移动实体集合；直接操作 Cesium 集合不会同步工具的 `shapes` 或触发工具事件。`clear()` 不移除图层且保留业务监听器；`destroy()` 完整释放实例并移除自建图层，但保留业务提供的外部图层。销毁后不能复用，请创建新实例。

## 五、配置项

### Draw 实例配置

```js
new Draw(viewer, {
  enabledRightMenu: true, // 是否启用右键菜单（默认 true）；false 时禁用所有场景的右键菜单
  enableEdit: true, // 是否支持编辑（默认 true）；false 时禁用所有编辑入口，autoEdit 随之失效
  autoEdit: false, // 绘制完成后是否自动进入编辑（默认 true）
  isContinued: false, // 是否连续绘制（默认 false）；true 时绘制完成后自动开始同类型下一次绘制
  style: {
    lineWidth: 2, // 线宽
    color: "#0092ff", // 颜色（线/面/点）
    pointSize: 10, // 点大小
    clampToGround: false, // 是否贴地（线/矩形/多边形/圆/椭圆），默认 false 不贴地
  },
});
```

> `clampToGround`：`true` 贴地（随地形起伏渲染，面/椭圆不再支持轮廓线 outline）；`false` 不贴地（默认，沿椭球高度 0 渲染）。仅对线、矩形、多边形、圆、椭圆生效，点不受影响。可在实例默认样式设置，也可在 `startDraw` 的 `style` 中单独覆盖。

### startDraw 每次绘制配置

```js
draw.startDraw({
  id: "customId", // 自定义实体 id（不传自动生成；传了则覆盖同 id 旧实体）
  type: "circle", // 必传：line / point / rect / polygon / circle / ellipse
  style: { color: "#00ff00", clampToGround: true }, // 本次样式，覆盖默认
  success: fn, // 可选：绘制完成回调（与 Promise 二选一，传了则不返回 Promise）
});
// 返回值：传 success → undefined；不传 → Promise<{ id, positions, type }>
```

## 六、常见问题

**Q1：双击结束画线时多画了一个点 / 第一个点双击就退出？**
已处理：0 个点时双击不结束；第一个点刚画完（500ms 内）双击会回退多加的点，只保留第一个点。

**Q2：矩形拖动角点变成四边形？**
不会。矩形用对角点模型 + 联动编辑，拖任意角都保持矩形。

**Q3：多边形/矩形轮廓线不显示或有警告？**
已处理：面实体显式 `height: 0`（贴地不支持 outline），且不设置 zIndex（有 height 时 zIndex 无效）。

**Q4：想画完不自动进入编辑？**
`new Draw(viewer, { autoEdit: false })`，之后点击实体或右键菜单「开始编辑」进入。若想**彻底禁用编辑**（点击 / 右键「开始编辑」/ 自动编辑均不可用，仅保留右键「删除」），设置 `new Draw(viewer, { enableEdit: false })`。

**Q5：如何删除单个实体？**
右键该实体 → 菜单「删除」，或 `draw.removeGraphic(id)`；删除正在编辑的实体会自动退出编辑。

**Q6：运行时禁用编辑会发生什么？**
设置 `draw.enableEdit = false` 会立即结束当前编辑，释放辅助点，恢复进入拖拽前的相机开关与光标；重新设为 true 后可再次点击编辑。

**Q7：如何连续绘制多个同类型图形？**
设置 `new Draw(viewer, { isContinued: true })`，绘制完成后自动开始同类型下一次绘制。也可运行时切换：`draw.isContinued = true`。停止连续绘制只需设回 `false` 或调用 `draw.stopDraw()`。连续绘制时不会自动进入编辑（`autoEdit` 失效）。

## 七、生命周期迁移与异常处理

- 取消、切换绘制类型、清空、销毁、点数不足作废时，当前 Promise 以 `AbortError` 拒绝，不再永久等待。必须在 `.catch()` 或 `try/catch` 中区分正常取消和真正错误。
- `clearDrawing()` 保留同一个会话与 Promise，仅清空控制点重新画；不重复发 `drawStart`。
- 回调模式依然返回 undefined，取消时不调用 success；初始化参数错误同步抛出。Promise 模式初始化错误以原始错误拒绝。
- 不支持的类型、非法 ID/颜色/尺寸会被拒绝。绘制同 ID 在开始时移除旧图形，取消不恢复；回显 ID 冲突始终拒绝。
- `editStart` 在辅助点及监听安装完成后触发，`editStop` 在资源释放和状态清空后触发。回调中可开启新交互；监听器同步异常及异步拒绝记录到 console，不阻断其他监听器。
- `clear()` 清空期间的 `editStop` 回调不能重新加载或绘制，防止新图形被同次清空；清理完成后的 `removeGraphic` 回调可以启动新交互。
- `destroy()` 幂等，取消未完成绘制、清理全部图形、菜单、监听器并恢复工具接管的 Viewer 双击操作；仍会通知已完成图形的删除事件。多工具共享 Viewer 时由最后一个工具恢复双击操作。
- 默认图层挂载未完成时也可以销毁，`ready` 完成后会移除已销毁实例的图层；外部图层由业务管理。

```js
// 组件卸载时：先释放工具，再按业务所有权处理 Viewer/外部图层。
draw.destroy();
// 页面示例：await drawDemo.start("line")，正常取消返回 null。
```

## 八、几何范围、性能和菜单样式

仅有两个顶点的线段：橙色平移手柄保留在线段中心，插点辅助手柄位于从起点到终点的四分之一处，避免两者重合；增加顶点后恢复各段中点插点，删除回两个顶点时自动重新分离。

圆和椭圆的中心用于整体平移，拖动轴端控制点调整半径或半轴；中心重叠的控制点与橙色手柄具有相同平移行为。

工具面向局部区域绘制：中点、中心和平移处理 ±180° 经度环绕；纬度越界的拖拽保留上一合法位置。圆/椭圆仍基于局部近似，控制点不代表精确测地轮廓，不用于全球大范围或极区精确测绘。多边形自交与面积拓扑验证不在本次范围内。

交互与回显共用合法性规则：零宽高矩形、零半径、非法椭圆半轴不会提交；非法点击继续等待有效控制点，非法拖拽保留上一合法数据。椭圆预览短轴限制到长轴，但最终点击仍须满足短轴不大于长轴。

空闲主实体固定为静态属性，进入编辑后恢复动态绑定；辅助点按需创建，退出编辑后释放。支持 `requestRenderMode`，修改通过工具 API 才会保证渲染刷新；不要直接修改内部模型。

右键菜单仍挂载到 `document.body`，类名保持 `.x-contextmenu`、`.x-contextmenu-item`、`.x-edit`、`.x-delete`、`.x-delete-point`。默认样式改为低优先级 `:where()`，普通全局 CSS 可覆盖颜色、间距和悬停色，无需 `!important`。Vue scoped 样式无法命中 body 下的菜单，须使用非 scoped 样式。禁止覆盖定位属性 `position/left/top`；菜单在视口边缘自动调整。

```css
.x-contextmenu {
  background: #fafafa;
}
.x-contextmenu .x-delete:hover {
  background: #ffdede;
}
```

### 9.4 `startDraw(options)` 参数详解

| 参数              | 类型       | 必填 | 默认值         | 说明                                                                       |
| ----------------- | ---------- | ---- | -------------- | -------------------------------------------------------------------------- |
| `options.type`    | `string`   | ✅   | —              | 图形类型：`line` / `point` / `rect` / `polygon` / `circle` / `ellipse`     |
| `options.id`      | `string`   | ❌   | 自动生成       | 自定义实体 ID；不传则由 `Cesium.createGuid()` 生成；传 `null` / 空串会抛错 |
| `options.style`   | `object`   | ❌   | `defaultStyle` | 本次绘制的样式覆盖，字段同 `config.style`                                  |
| `options.data`    | `Array`    | ❌   | `[]`           | 初始坐标 `[[lon, lat], ...]`；空数组表示交互绘制，非空则直接生成图形       |
| `options.success` | `Function` | ❌   | —              | 绘制完成回调，收到 `{ id, positions, type }` 独立快照；与 Promise 二选一   |

**返回值**：

| 调用方式          | 返回值                                                       |
| ----------------- | ------------------------------------------------------------ |
| 传 `success` 回调 | `undefined`；结果通过回调返回                                |
| 不传 `success`    | `Promise<{ id, positions, type }>`；取消以 `AbortError` 拒绝 |

**取消路径**：`stopDraw()`、`clearDrawing()`、切换绘制类型、点数不足作废、`clear()`、`destroy()` 均会结算 Promise（`AbortError` 拒绝或 `null` 结算），不会永久挂起。

#### Promise 模式示例

```js
const draw = new DrawTool(viewer);
await draw.ready;

// 正常完成
try {
  const result = await draw.startDraw({
    type: "polygon",
    id: "my-polygon-1",
    style: { color: "#ff0000", lineWidth: 3 },
  });
  console.log("绘制完成:", result); // { id: "my-polygon-1", positions: [...], type: "polygon" }
} catch (err) {
  if (err.name === "AbortError") {
    console.log("绘制被取消");
  } else {
    console.error("绘制失败:", err);
  }
}

// 带初始坐标（直接生成，无需交互）
const result = await draw.startDraw({
  type: "line",
  data: [
    [116.39, 39.91],
    [116.40, 39.92],
    [116.41, 39.91],
  ],
});
console.log("直接生成:", result);
```

#### 回调模式示例

```js
const draw = new DrawTool(viewer);
await draw.ready;

// 回调模式（返回 undefined）
const returnValue = draw.startDraw({
  type: "rect",
  style: { color: "#00ff00" },
  success: (result) => {
    console.log("矩形绘制完成:", result);
    // result: { id: "...", positions: [...], type: "rect" }
  },
});
console.log("返回值:", returnValue); // undefined
```

#### 取消路径测试

```js
const draw = new DrawTool(viewer);
await draw.ready;

// 1. 通过 stopDraw() 取消
const promise1 = draw.startDraw({ type: "line" });
draw.stopDraw();
try {
  await promise1;
} catch (err) {
  console.log(err.name); // "AbortError"
  console.log(err.message); // "绘制已取消"
}

// 2. 通过 clearDrawing() 取消（清除控制点重新开始）
const promise2 = draw.startDraw({ type: "polygon" });
draw.clearDrawing();
try {
  await promise2;
} catch (err) {
  console.log(err.name); // "AbortError"
}

// 3. 通过切换绘制类型取消
const promise3 = draw.startDraw({ type: "circle" });
draw.startDraw({ type: "ellipse" }); // 切换类型会取消上一个
try {
  await promise3;
} catch (err) {
  console.log(err.name); // "AbortError"
}

// 4. 通过 clear() 取消
const promise4 = draw.startDraw({ type: "rect" });
draw.clear();
try {
  await promise4;
} catch (err) {
  console.log(err.name); // "AbortError"
}

// 5. 通过 destroy() 取消
const promise5 = draw.startDraw({ type: "line" });
draw.destroy();
try {
  await promise5;
} catch (err) {
  console.log(err.name); // "AbortError"
}
```
