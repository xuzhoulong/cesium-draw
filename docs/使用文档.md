# 绘制工具使用文档（DrawTool）

基于 Cesium 的地图图形绘制工具，支持绘制**线、点、矩形、多边形、圆、椭圆**，画完可编辑（拖拽顶点 / 整体移动）、右键菜单操作、事件监听。

---

## 一、快速开始

### 1. 引入

页面需通过本地静态服务器访问（ES Module 不支持 `file://` 直接打开），例如：

```bash
# 项目根目录启动静态服务
http-server
# 浏览器访问 http://localhost:8080
```

`index.html` 已引入离线 Cesium 与绘制工具模块。

### 2. 初始化

```js
import Draw from "./js/drawTool.js";
import initGui from "./js/gui.js";

// 创建 Cesium Viewer（省略配置）
const viewer = new Cesium.Viewer("map", { ... });

// 创建绘制工具实例
const draw = new Draw(viewer, {
  isAutoEditing: true,                          // 可选：绘制完自动进入编辑，默认 true
  style: { lineWidth: 2, color: "#0092ff", pointSize: 10 }, // 可选：默认样式
});

// 创建 lil-gui 面板（右上角按钮组）
initGui(draw, viewer);
```

## 二、绘制操作

### 方式一：面板按钮

面板默认提供：**点 / 线 / 矩形 / 多边形 / 圆 / 椭圆 / 停止绘制 / 重新绘制 / 清空图层**。

点击对应按钮后，在地图上按交互规则绘制。

### 方式二：代码调用

```js
// 回调方式
draw.startDraw({
  type: "line",
  style: { color: "#ff0000" }, // 可选，覆盖默认样式
  id: "myLine", // 可选，自定义实体 id
  success: (result) => {
    console.log(result.id, result.positions, result.type);
  },
});

// 异步方式
const result = await draw.startDraw({ type: "rect" });
console.log(result);
// result = { id, positions, type }
```

### 各类型的绘制交互

| 类型       | 交互步骤                                   | 完成方式       |
| ---------- | ------------------------------------------ | -------------- |
| **线**     | 单击加点；右键删除最后一点                 | 双击结束       |
| **点**     | 鼠标移动有预览点                           | 单击放置即完成 |
| **矩形**   | 第一点定起点，第二点定对角（预览实时跟随） | 第二点点击完成 |
| **多边形** | 单击加点（预览面实时闭合）；右键删点       | 双击闭合结束   |
| **圆**     | 第一点圆心，第二点半径点（预览实时跟随）   | 第二点点击完成 |
| **椭圆**   | 三点：圆心 → 长半轴点 → 短半轴点           | 第三点点击完成 |

> 绘制过程中所有类型均可用**右键撤销**上一步（线/多边形删点，矩形/圆/椭圆回退参数点）。

### 停止 / 重新绘制

| 按钮         | 作用                                               |
| ------------ | -------------------------------------------------- |
| **停止绘制** | 停止当前绘制并**删除未完成的实体**（不保留半成品） |
| **重新绘制** | 清除当前已画的半成品，**保持绘制状态**原地重画     |
| **清空图层** | 清空地图上**所有**已画实体                         |

代码：`draw.stopDraw()` / `draw.clearDrawing()` / `draw.clear()`

## 三、编辑操作

绘制完成后默认自动进入编辑（`isAutoEditing: true`），也可点击实体或右键菜单进入。

| 操作                 | 行为                                                   |
| -------------------- | ------------------------------------------------------ |
| 按住**顶点**拖动     | 修改该顶点位置（矩形对角联动，保持矩形；其余独立拖拽） |
| 按住**实体主体**拖动 | **整体移动**整个实体（线/面/圆/椭圆）                  |
| 点击空白处           | 退出编辑                                               |
| 点击其他实体         | 切换编辑到该实体                                       |
| 右键实体             | 弹出菜单：**开始编辑 / 停止编辑 / 删除**               |

> 悬停在线/面上会显示「左键点击进行编辑，右键菜单」提示。

## 四、获取绘制结果

### 1. 绘制完成回调 / Promise

```js
// 回调
draw.startDraw({ type: "line", success: (r) => console.log(r) });

// 异步
const r = await draw.startDraw({ type: "polygon" });
// r = { id: 实体id, positions: 坐标数组, type: "polygon" }
```

### 2. 事件监听（编辑后数据）

```js
// 编辑完一个点（拖拽松手）后触发
draw.on("editMovePoint", (data) => {
  console.log("编辑完点", data); // { id, positions, type }
});

// 结束编辑后触发
draw.on("editStop", (data) => {
  console.log("结束编辑", data); // { id, positions, type }
});

// 移除监听
draw.off("editMovePoint", handler);
```

> `positions` 是**实时引用**：编辑后直接读 `data.positions` 即为最新坐标；矩形返回 4 个角点，圆返回 `[圆心, 半径点]`，椭圆返回 `[圆心, 长轴点, 短轴点]`。

## 五、配置项

### Draw 实例配置

```js
new Draw(viewer, {
  isAutoEditing: false, // 绘制完成后是否自动进入编辑（默认 true）
  style: {
    lineWidth: 2, // 线宽
    color: "#0092ff", // 颜色（线/面/点）
    pointSize: 10, // 点大小
    clampToGround: false, // 是否贴地（线/矩形/多边形/圆/椭圆），默认 false 不贴地
  },
});
```

> `clampToGround`：`true` 贴地（随地形起伏渲染，面/椭圆不再支持轮廓线 outline）；`false` 不贴地（默认，沿椭球高度 0 渲染）。仅对线、矩形、多边形、圆、椭圆生效，点不受影响。可在实例默认样式设置，也可在 `startDraw` 的 `style` 中单独覆盖。

### startDraw 每次绘制配置

```js
draw.startDraw({
  id: "customId", // 自定义实体 id（不传自动生成；传了则覆盖同 id 旧实体）
  type: "circle", // 必传
  style: { color: "#00ff00", clampToGround: true }, // 本次样式，覆盖默认
  success: fn, // 可选（与 Promise 二选一）
});
```

## 六、常见问题

**Q1：双击结束画线时多画了一个点 / 第一个点双击就退出？**
已处理：0 个点时双击不结束；第一个点刚画完（500ms 内）双击会回退多加的点，只保留第一个点。

**Q2：矩形拖动角点变成四边形？**
不会。矩形用对角点模型 + 联动编辑，拖任意角都保持矩形。

**Q3：多边形/矩形轮廓线不显示或有警告？**
已处理：面实体显式 `height: 0`（贴地不支持 outline），且不设置 zIndex（有 height 时 zIndex 无效）。

**Q4：想画完不自动进入编辑？**
`new Draw(viewer, { isAutoEditing: false })`，之后点击实体或右键菜单「开始编辑」进入。

**Q5：如何删除单个实体？**
右键该实体 → 菜单「删除」；删除正在编辑的实体会自动退出编辑。
